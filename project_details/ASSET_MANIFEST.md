# Project Details Asset Manifest

**Purpose:** Classify the supplied specification and image assets before they are used by the Phase 0 mobile implementation.

## Classification

- **Beta authority:** Required or directly usable for the current beta contract.
- **Reference:** Visual or interaction inspiration only; do not copy deferred scope.
- **Deferred:** Contains out-of-scope behavior, unapproved identity/content, or a privacy anti-pattern.
